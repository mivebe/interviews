# Bar Chart Renderer

A vanilla JavaScript live-coding exercise that renders horizontal bar charts from data.

## Live Demo

[mivebe-interviews.netlify.app/projects/barchart-live-coding](https://mivebe-interviews.netlify.app/projects/barchart-live-coding/)

## About

A live-coding interview submission that dynamically renders a horizontal bar chart. Bars are sized proportionally based on their numeric values relative to the maximum value in the dataset.

## Files

| File | Description |
|---|---|
| `draw.html` | Entry point |
| `draw.js` | Bar chart rendering logic |
| `draw.css` | Chart styles |

## Running

Open `draw.html` in a browser. No build step or dependencies required.
