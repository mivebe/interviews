# Kanbanize Coding Tasks

A collection of four interview coding tasks implemented as standalone HTML pages.

## Live Demo

[mivebe-interviews.netlify.app/projects/kanbanize-app](https://mivebe-interviews.netlify.app/projects/kanbanize-app/)

## About

Four distinct coding challenges completed for a Kanbanize interview, each demonstrating different JavaScript skills -- from functional programming and date logic to DOM manipulation and data visualization.

## Tasks

| Task | Description |
|---|---|
| **Task 1** | `groupByNumber` -- Groups array data by a numeric criterion function |
| **Task 2** | `getWorkday` -- Calculates the next workday given configurable work week parameters |
| **Task 3** | `DOMManipulator` -- Class for dynamically applying CSS properties and event listeners |
| **Task 4** | CSV bar chart -- Reads CSV data and renders a bar chart with day/week/month period controls |

## Tech Stack

Vanilla JavaScript, TypeScript, HTML, CSS

## Running

Open `index.html` in a browser for the task menu, or navigate directly to individual task files (e.g., `task_3/task_3.html`). No build step required.
