# Data Structures and Patterns

JavaScript implementations of fundamental data structures and language patterns.

## About

Educational implementations from a live-coding session covering three linked list variants, function currying with partial application, and OOP context binding with `call`, `apply`, and `bind`.

## Files

| File | Description |
|---|---|
| `Single_Linked_List.js` | Singly linked list with insert, delete, and traversal |
| `Double_Linked_List.js` | Doubly linked list with bidirectional node links |
| `Circular_Linked_List.js` | Circular linked list where the tail points to the head |
| `currying.js` | Function currying and partial application examples |
| `oop-context-change.js` | Demonstrates `this` context binding with call/apply/bind |

## Running

```bash
node Single_Linked_List.js
node Double_Linked_List.js
node Circular_Linked_List.js
node currying.js
node oop-context-change.js
```
