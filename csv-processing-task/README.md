# CSV Processing Examples

Multiple approaches to CSV data parsing and export in JavaScript.

## About

A collection of CSV processing implementations demonstrating different techniques -- an HTML-based table-to-CSV exporter and a Node.js regex-based CSV parser.

## Files

| File | Description |
|---|---|
| `export to csv.html` | HTML page that exports table data to CSV format |
| `process CSV Node.js` | Node.js implementation for parsing CSV files with regex |

## Running

- Open the HTML file in a browser for the CSV export demo
- Run the Node.js file with `node "process CSV Node.js"`
