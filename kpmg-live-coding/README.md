# Longest String Finder

A JavaScript utility function that finds and returns the longest string from a mixed-type array.

## About

Live-coding algorithm task completed for a KPMG interview. The function iterates through an array of mixed types, filters for strings, and returns the longest one. Includes a Jest test suite with multiple edge cases.

## Files

| File | Description |
|---|---|
| `longestString.js` | Implementation of the `longestString` function |
| `longestString.test.js` | Jest test cases with input/expected output |
| `kpmg_live_coding_task.png` | Original task description screenshot |

## Running

```bash
npx jest
```

Requires Jest installed globally or via npx.
